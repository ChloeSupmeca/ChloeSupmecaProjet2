# CavitY-Taskforce

CavitY-Taskforce est un jeu vidéo qui consiste à guérir des patients ayant des pathologies.
Vous incarnez le dentiste.

Pour vous déplacer :
A gauche : Appuyez sur Q
A droite : Appuyez sur D
En haut : Appuyez sur Z
En bas : Appuyez sur S

Pour prendre des gants :

Appuyez sur G

Pour jetter les gants ou instruments :

S'approcher de la poubelle et appuyer sur W

Pour soigner :

Appuyez sur K
